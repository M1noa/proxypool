# Agent instructions

## Commits

- `M1noa <git@minoa.cat>` is the only author and committer. Do not set
  `GIT_AUTHOR_*` or `GIT_COMMITTER_*`, and do not change `user.name` or
  `user.email`.
- No AI attribution of any kind: no `Co-Authored-By` trailers, no
  `Generated with ...` lines, no tool or assistant name anywhere in the message.
  That covers Codebuff, Claude, Copilot, Cursor and the rest.
- Commit messages are the change and why, nothing else — a subject in the same
  style as `git log`, and a body only when the reasoning is not obvious.
- The one exception is a specific commit the user explicitly says to author or
  attribute differently.
